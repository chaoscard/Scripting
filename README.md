<h2 id="pix-scripting">🎨 Pix-Scripting</h2>

> 专为 iOS / iPadOS 打造的液态玻璃（Liquid Glass）风格 Pixiv 客户端脚本。

#### ✨ 特色功能

- 🎨 **液态玻璃与全景沉浸**：全透明贯穿导航，支持空间物理光影、极光等 6 种动态环境光引擎随作品流光溢彩。
- 🖼️ **原图流式浏览 & 动图转码**：插画/漫画长图秒开与分块预取；动态图（Ugoira）原生硬件加速合成导出 MP4 / GIF。
- 📖 **小说日式文库本阅读**：支持横向流式与纵向文库本（注音/标点悬挂），预设多种主题并支持一键导出 EPUB 电子书。
- 🤖 **AI 深度集成与多模态扩展**：支持自定义模型（OpenAI / Gemini / Claude 等），提供画作画面解析、提示词逆向、AI 生图/图生图扩展及小说流式翻译与速读摘要。
- 🏝️ **系统级深度集成**：灵动岛 / 锁屏实时下载进度、后台任务保活、桌面画框小组件、CBZ / EPUB 离线归档。
- 🔒 **纯净安全与本地优先**：官方 PKCE 安全登录，凭据独立 Keychain 隔离，数据本地沙盒落盘并支持 iCloud 同步。

#### 📥 快速安装

1. 安装 **[Scripting](https://apps.apple.com/app/scripting/id6477833076)** App；
2. 下载并导入最新发布包：[`Release/Pix-Scripting.scripting`](https://raw.githubusercontent.com/chaoscard/Scripting/main/Release/Pix-Scripting.scripting)；
3. 支持在脚本设置内检测并一键无缝更新。
